# VvPD Labs

Лабораторные работы по курсу «Введение в профессиональную деятельность» (VvPD).

| Лабораторная | Тема | Каталог |
| --- | --- | --- |
| Lab 1 | Языки программирования, терминал и Git | [`VvPD-Lab1`](VvPD-Lab1) |
| Lab 2 | Язык C изнутри: данные, управление, время выполнения и сборка | [`VvPD-Lab2`](VvPD-Lab2) |
| Lab 3 | Строки, кодировки, Base64, регулярные выражения и URI | [`VvPD-Lab3`](VvPD-Lab3) |
| Lab 4 | Указатели, динамическая память, структуры, файлы и свои типы | [`VvPD-Lab4`](VvPD-Lab4) |
| Lab 5 | Командная строка, файловая БД и собственный язык запросов | [`VvPD-Lab5`](VvPD-Lab5) |

Каждая работа самодостаточна: в её каталоге есть `README.md` с описанием,
`REPORT.md` с отчётом, `Makefile` и исходные файлы. Сборка выполняется из
каталога соответствующей лабораторной, например:

```sh
cd VvPD-Lab2
make
```
